# Prompt para generar ícono — YT-DownLoader

## Prompt (Gemini / DALL-E / Midjourney / Ideogram)

```
Design a minimal, modern app icon for a video/audio downloader desktop application called "YT-DownLoader". The icon should combine a play button triangle (▶) and a downward arrow (↓) into one unified symbol. Use a flat design style with no gradients. Color palette: dark navy background (#0f172a), bright cyan accent (#38bdf8) for the main symbol. Clean geometric shapes, no text, no borders. Square icon with rounded corners, suitable for a desktop application icon. Style: modern, tech, HUD-inspired. 1024x1024 pixels, transparent or solid dark background.
```

## Formatos de exportación necesarios

| Archivo | Tamaño | Para qué |
|---|---|---|
| `icon.png` | 1024x1024 | Fuente principal |
| `icon.ico` | 256x256 (multi-res) | Windows exe + installer |
| `icon.icns` | 1024x1024 | macOS app bundle |
| `icon.png` | 512x512 | Linux .desktop |

## Herramientas para conversión

- **PNG → ICO**: https://realfavicongenerator.net/ o `png2ico` (CLI)
- **PNG → ICNS**: https://www.iconvert.info/ o `png2icns` (CLI)
